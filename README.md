## ⚡ Featured Projects

### 📡 [SentinelX](https://github.com/JS-Aakash/SentinelX) — AI-Powered Industrial Asset Intelligence Platform
*`React` · `FastAPI` · `Node.js` · `PostgreSQL (TimescaleDB)` · `MQTT` · `XGBoost` · `Docker`*

> Scalable full-stack predictive maintenance platform empowering industrial asset monitoring with real-time IoT analytics and AI predictions.

- Built a full-stack predictive maintenance system streaming real-time IoT sensor telemetry via **MQTT** into a time-series optimized **PostgreSQL (TimescaleDB)** engine.
- Developed an **XGBoost-based Machine Learning pipeline** for equipment health prediction, anomaly detection, and **Remaining Safe Operating Time (RSOT)** estimation.
- Implemented real-time sensor streaming dashboards, historical analytics, AI model versioning, and interactive monitoring interfaces.
- Designed a modular microservice architecture with FastAPI/Node.js REST endpoints, secure authentication, and cloud-ready Docker deployment.

> End-to-end DevOps management platform streamlining software lifecycle from planning to production monitoring.

- Integrated **GitHub APIs** for issue tracking, pull request management, CI/CD monitoring, and repository analytics in a unified dashboard.
- Developed modules for requirements management, **Kanban boards**, real-time project chat, team collaboration, and system monitoring.
- Implemented **AI-powered features** including issue resolution assistance, automated pull request generation, revert-based rollback workflows, and release readiness validation with human approval controls.

---

### 🧠 [ContextAI](https://github.com/JS-Aakash) — Retrieval-Augmented Generation (RAG) System
*`AWS (EC2, ECR, S3)` · `Docker` · `Vector Search` · `Python`*

> Production-ready RAG system retrieving relevant documents using vector similarity search to generate grounded LLM responses.

- Built an end-to-end pipeline for document ingestion, embedding generation, vector retrieval, and response synthesis exposed via scalable backend API.
- Dramatically reduced model hallucinations by grounding LLM responses in domain-specific contextual embeddings.
- Containerized and deployed on **AWS** leveraging cloud-native services for high availability, reliability, and scaling.

### 🛡️ [BaitBlocker](https://github.com/JS-Aakash) — Phishing & Domain Squatting Detection
*`Python` · `Scikit-learn` · `Random Forest` · `Chrome Extension`*

> Real-time phishing assessment tool built as a lightweight Chrome extension powered by ML.

- Designed & trained a **Random Forest-based model with 95% accuracy** by extracting 47+ structural & behavioral URL features, automated SSL certificate verification, and WHOIS checks.
- Developed a **Chrome extension** that provides real-time phishing assessments while browsing to safeguard user credentials.
- Optimized feature extraction and prediction latency for seamless browser integration.
